# WatermarkApp - 水印文件本地应用

WatermarkApp 是一款为 Windows 用户设计的桌面应用程序，可以方便地为图片添加文本或图片水印。它支持批量处理、多种自定义选项和模板保存功能。

## 主要功能

- **批量处理**: 一次性导入多张图片或整个文件夹进行处理。
- **多种水印类型**: 支持完全自定义的文本水印和图片水印。
- **实时预览**: 所有调整（位置、大小、旋转、透明度等）都能立即在预览窗口看到效果。
- **灵活的导出选项**: 自定义输出路径、文件名格式、图片质量和尺寸。
- **配置模板**: 保存你喜欢的水印样式，随时调用。
