# WatermarkApp - 一款功能丰富的本地水印工具

![PyQt6](https://img.shields.io/badge/UI-PyQt6-green?logo=qt)
![License](https://img.shields.io/badge/License-MIT-lightgrey)

WatermarkApp 是一款为 Windows 用户设计的桌面应用程序，可以方便、高效地为图片批量添加可完全自定义的文本或图片水印。

---

## ✅ 主要功能

本项目已完成需求文档中的所有核心功能及高级功能。

#### 文件处理
- [x] **多种导入方式**: 支持通过文件选择器、文件夹选择器以及直接拖拽文件/文件夹到主窗口进行导入。
- [x] **批量处理**: 可一次性处理大量图片。
- [x] **可视化列表**: 在左侧以“缩略图+文件名”的形式清晰展示所有待处理的图片。
- [x] **格式支持**: 支持 `JPEG`, `PNG`, `BMP`, `TIFF` 等主流图片格式的输入。
- [x] **灵活导出**:
    - [x] 自定义输出文件夹，并具备防止覆盖原图的安全检查。
    - [x] 提供**保留原名、添加前缀、添加后缀**三种文件命名规则。
    - [x] 可选择输出为 `PNG` 或 `JPEG` 格式。
    - [x] 针对 `JPEG` 格式，提供 0-100 的质量调节滑块。
    - [x] 支持在导出时按**百分比、宽度或高度**对图片进行缩放。

#### 水印定制
- [x] **双模式水印**: 支持**文字水印**和**图片水印**，可随时切换。
- [x] **丰富的文本样式**:
    - [x] 自定义文字内容、字体、字号。
    - [x] 通过调色板选择颜色，并通过滑块调节透明度。
    - [x] 一键设置**粗体**、**斜体**。
    - [x] 添加**阴影**和**描边**效果，增强可读性。
- [x] **强大的图片水印**:
    - [x] 支持选择本地图片（推荐使用PNG）作为水印。
    - [x] 按百分比缩放图片水印大小。
    - [x] 调节图片水印的整体透明度。

#### 布局与预览
- [x] **所见即所得**: 所有参数的调整都会在预览窗口中**实时**生效。
- [x] **精确定位**:
    - [x] 提供**九宫格**布局用于快速定位。
    - [x] 支持在预览图上直接用**鼠标拖拽**水印进行微调。
- [x] **任意旋转**: 通过滑块可对水印进行 -180° 到 +180° 的旋转。

#### 配置管理
- [x] **智能记忆**: 程序会自动保存用户上一次退出时的所有设置，并在下次启动时自动加载。
- [x] **模板管理**:
    - [x] 支持将当前所有复杂的水印设置保存为一个具名模板。
    - [x] 支持随时从已保存的模板列表中加载、删除模板。

## 🚀 安装与运行

#### 方式一：直接运行 (推荐)
1.  访问本项目的 [GitHub Releases 页面](https://github.com/atriirta/wh_PhotoWatermark2/releases/tag/v1.1.0)。
2.  下载最新的 `WatermarkApp.exe` 文件。
3.  双击运行即可。

#### 方式二：从源码运行 (适用于开发者)
1.  克隆本仓库：
    ```bash
    git clone https://github.com/atriirta/wh_PhotoWatermark2.git
    cd your-repository
    ```
2.  安装依赖：
    ```bash
    pip install -r requirements.txt
    ```
3.  运行主程序：
    ```bash
    python main.py
    ```

## 📖 使用说明

#### 第一步：导入图片
您有三种方式导入待处理的图片：
1.  点击 **`导入图片`** 按钮，在弹出的窗口中选择一张或多张图片。
2.  点击 **`导入文件夹`** 按钮，选择一个包含图片的文件夹，程序会自动筛选出所有支持的图片。
3.  直接从您的电脑桌面或文件管理器中，将**图片文件**或**文件夹**拖拽到程序主窗口的任意位置。
导入的图片会以缩略图的形式显示在左侧列表中。

#### 第二步：设置水印
1.  在右侧面板顶部选择水印类型：**`文字`** 或 **`图片`**。

2.  **如果选择 `文字` 水印**:
    - 在“文本内容”框中输入您想要的文字。
    - 通过下拉菜单选择字体，勾选“粗体”、“斜体”、“阴影”、“描边”来应用不同样式。
    - 拖动滑块或输入数字来调整字体“大小”和“透明度”。
    - 点击“选择颜色”按钮来更改文字颜色。

3.  **如果选择 `图片` 水印**:
    - 点击“选择图片...”按钮，加载您的Logo等图片作为水印。
    - 拖动“缩放”滑块，以相对于背景图的百分比来调整水印大小。
    - 拖动“透明度”滑块，调整图片水印的可见程度。

#### 第三步：调整通用样式
在“通用设置”区域，您可以：
1.  点击**九宫格按钮**将水印快速定位到图片的9个常用位置。
2.  在预览图上**按住鼠标左键并拖动**，对水印位置进行精确的微调。
3.  拖动**旋转滑块**来设置水印的旋转角度，或点击“归零”按钮快速重置。

#### 第四步：配置导出选项
在导出前，您可以在“导出设置”区域进行详细配置：
1.  **命名规则**: 选择保留原文件名，或添加自定义的前缀/后缀。
2.  **格式**: 选择输出为无损的 `PNG`（推荐）或有损压缩的 `JPEG`。选择JPEG时，下方会出现质量滑块。
3.  **调整尺寸 (可选)**: 勾选此项，可以按百分比、固定宽度或固定高度对输出图片进行缩放。

#### 第五步：导出
1.  点击最下方的 **`导出所有图片`** 按钮。
2.  在弹出的窗口中，选择一个用于保存输出文件的文件夹。**注意：不能选择与原图相同的文件夹。**
3.  等待处理完成的提示框弹出即可。

#### (高级) 模板管理
如果您有一套常用的水印配置，可以：
1.  点击“通用设置”中的 **`管理模板...`** 按钮。
2.  在弹出的对话框中，输入模板名称并点击“保存”，即可将当前所有设置保存起来。
3.  未来，您可以随时通过此对话框“加载”或“删除”已保存的模板。

## 🛠️ 技术栈
- **Python 3**
- **PyQt6**: 用于构建图形用户界面。
- **Pillow**: 用于图像处理（在代码中主要通过Qt的图像类`QPixmap`间接使用其能力）。
- **PyInstaller**: 用于将Python脚本打包成独立的可执行文件。
